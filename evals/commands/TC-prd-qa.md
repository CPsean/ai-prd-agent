| 字段 | 内容 |
|------|------|
| **状态** | — |
| **功能编号** | KQA-QRY-001 |
| **测试目标** | 验证含明确锚点但领域模糊（无法判断是问规则还是字段）时，AI 输出一句话确认方向，且最多追问一次 |

**检查要点**
- [ ] 追问内容简洁（一句话，非多段）
